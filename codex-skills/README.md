# Disco Elysium — навыки для Codex

Русская версия раздела `codex-skills/` из [liigoQi/disco-elysium](https://github.com/liigoQi/disco-elysium/tree/82489249e6a7b24c0bfd7330b2b504baca8505c2/codex-skills) с авторской персонализацией: один голос Психики заменён личным навыком «Рыцарь пепельных сердец» с ядром «Смысл из пепла». Это авторский навык в духе игры. 24 внутренних голоса + переключатель режима + справочник.

> Демоны ярости живут в зеркалах. Они здесь как дома.
> Даже в самой прозрачной воде можно утонуть, если она глубока.

## Как устроен набор

DE-режим здесь — договорённость внутри текущего разговора. Можно попросить включить или выключить его; после включения голоса становятся дополнительным слоем внутреннего монолога. Отдельный навык лучше называть прямо, а не ожидать, что он вмешается в любую беседу.

Переключатель сохраняет исходное разделение: реплика персонажа не становится указанием для основного ответа Codex.

Примеры запросов для будущего использования набора:

- «Используй de-logic, чтобы разобрать этот код».
- «Электрохимия, я сегодня устал».
- «Внутренняя империя, как тебе название этой функции?».
- «Рыцарь пепельных сердец, мне страшно начинать заново» или «Используй de-knight-of-ashen-hearts».
- «Включи DE-режим» / «Выключи DE-режим».

## Формат ответа

Цвет голоса определяется группой: 🔵 Интеллект, 🟣 Психика, 🔴 Физиология, 🟡 Моторика. Эмодзи ставится внутри первых скобок перед названием: `[🔵 Логика] [Успех/Провал] — текст реплики`.

## Пример интонации

```text
Пользователь: Логика, я совсем запутался.

[🔵 Логика] [Провал] — Твои рассуждения — сплошная каша. А ведёт к Б,
Б ведёт к В, В ведёт к... Погоди, что такое В? Ты забыл.
```
Это пример реплики из переведённого файла, а не результат запуска установленного навыка.
