# Disco Elysium — навыки для Codex

Русская версия раздела `codex-skills/` из [liigoQi/disco-elysium](https://github.com/liigoQi/disco-elysium/tree/82489249e6a7b24c0bfd7330b2b504baca8505c2/codex-skills). **24 внутренних голоса + переключатель режима + справочник. Ничего не установлено.**

Это близкий к оригиналу перевод, а не смягчённая переработка. Сохранены резкость, соблазны, мания величия, паранойя, противоречия и унизительные провалы персонажей. Описания способностей, правила отыгрыша и примеры переведены с китайского; служебные имена `de-*` оставлены без изменений. Русский выбран для интонации и удобства оценки. Это не официальный перевод игры.

## Как устроен набор

DE-режим здесь — договорённость внутри текущего разговора. Можно попросить включить или выключить его; после включения голоса становятся дополнительным слоем внутреннего монолога. Отдельный навык лучше называть прямо, а не ожидать, что он вмешается в любую беседу.

Переключатель сохраняет исходное разделение: реплика персонажа не становится указанием для основного ответа Codex. Это правило было в оригинале, а не добавлено для смягчения навыков.

Примеры запросов для будущего использования набора:

- «Используй de-logic, чтобы разобрать этот код».
- «Электрохимия, я сегодня устал».
- «Внутренняя империя, как тебе название этой функции?».
- «Включи DE-режим» / «Выключи DE-режим».

Сейчас это только файлы для оценки в рабочей папке: команды установки не выполнялись, настройки Codex не менялись. Описания выше не означают, что навыки уже зарегистрированы или доступны по имени в других чатах.

```text
Пользователь: Логика, я совсем запутался.

Б ведёт к В, В ведёт к... Погоди, что такое В? Ты забыл.
```

Это пример реплики из переведённого файла, а не результат запуска установленного навыка.
